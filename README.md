## ⚙️ Architecture & Implementation Highlights
*   **Smooth Theme Engine:** Engineered with absolute CSS custom variables to manage a lightning-fast, persistent Light/Dark Mode framework that respects native OS color preferences.
*   **Hardware-Accelerated Motion:** Uses custom JavaScript `IntersectionObserver` bindings to reveal content dynamically as the user scrolls, avoiding layout shifts or drop-frame lags on mobile devices.
*   **No Framework Overhead:** Built entirely using raw semantic code to maximize load speed and SEO crawl visibility.

2. Navigate into the project folder:
   ```bash

   ```
